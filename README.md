# CompTIA PenTest+ PT0-003 Quiz

Interactive practice exam for CompTIA PenTest+ (PT0-003) certification.

## Features

- **534 Practice Questions** across two question banks
- **Practice Mode** - Check answers immediately after each question
- **Exam Mode** - See results only at the end
- **Shuffle** - Randomize question order
- **Progress Tracking** - Track correct/incorrect answers
- **Multi-select Support** - For questions requiring multiple answers
- **Category Tags** - Questions organized by exam domains
- **Question Navigator** - Jump to any question instantly
